문제 1. 출석번호로 학생 찾기 (BST)

선생님이 출석번호와 이름을 입력하면 번호 순서대로 출석부를 출력하고, 번호로 학생 이름을 찾는 프로그램을 만드세요. 이미 있는 번호는 무시합니다.

Write a program that stores student ID numbers and names, prints the attendance list in ID order, and searches for a student by ID. Ignore IDs that already exist.

입력과 출력 예시 / Sample Input and Output

  • 입력 / Input: 15 민준, 8 서연, 22 지호, 4 하윤, 11 도윤
  • 찾기 / Search: 11, 7
  • 출력 / Output: 번호 순서대로 출석부, 11번은 도윤, 7번은 없음
    Attendance list in ascending order; ID 11 is Doyun, and ID 7 does not exist.

힌트 / Hints

  • 왼쪽 자식은 부모보다 작은 번호, 오른쪽 자식은 큰 번호입니다.
    The left child has a smaller ID than its parent; the right child has a larger ID.
  • 중위 순회 inorder: left, root, right를 하면 번호가 작은 것부터 출력됩니다.
    Inorder traversal (left, root, right) prints IDs from smallest to largest.
풀이 코드 보기 / View Solution Code (p1.py) 
class Node:
    def __init__(self, student_id, name):
        self.student_id = student_id
        self.name = name
        self.left = None
        self.right = None


def insert(root, student_id, name):
    if root is None:
        return Node(student_id, name)

    if student_id < root.student_id:
        root.left = insert(root.left, student_id, name)
    elif student_id > root.student_id:
        root.right = insert(root.right, student_id, name)
    # 같은 ID이면 아무 작업도 하지 않아 중복을 무시합니다.
    return root


def search(root, student_id):
    while root is not None:
        if student_id == root.student_id:
            return root
        if student_id < root.student_id:
            root = root.left
        else:
            root = root.right
    return None


def inorder(root):
    if root is None:
        return
    inorder(root.left)
    print(f"{root.student_id}번 {root.name}")
    inorder(root.right)


# 메인 프로그램 / Main program
root = None
students = [
    (15, "민준"),
    (8, "서연"),
    (22, "지호"),
    (4, "하윤"),
    (11, "도윤"),
]

for student_id, name in students:
    root = insert(root, student_id, name)

print("[출석부]")
inorder(root)

for student_id in [11, 7]:
    result = search(root, student_id)
    if result:
        print(f"{student_id}번은 {result.name}입니다.")
    else:
        print(f"{student_id}번 학생은 없습니다.")

문제 2. 번호표를 순서대로 넣으면? (AVL)

은행 번호표 1번부터 15번까지가 차례로 들어옵니다. 일반 BST와 AVL 트리에 똑같이 넣고, 트리 높이와 15번을 찾을 때 비교한 횟수를 비교하세요.

A bank issues ticket numbers from 1 through 15 in ascending order. Insert the same sequence into a regular BST and an AVL tree, then compare their heights and the number of comparisons needed to find ticket 15.

입력과 출력 예시 / Sample Input and Output

  • 입력 / Input: 1, 2, 3, ..., 15 (오름차순 / ascending order)
  • 출력 / Output: 각 트리의 높이와 15번 검색 비교 횟수
    The height of each tree and the number of comparisons required to search for 15.

힌트 / Hints

  • BST에 오름차순으로 넣으면 오른쪽 자식만 생겨 연결 리스트처럼 됩니다.
    Inserting ascending values into a BST creates only right children, making it resemble a linked list.
  • AVL은 왼쪽과 오른쪽 높이 차이(균형 값)가 2가 되면 회전 rotation으로 고칩니다.
    An AVL tree uses rotations when the height difference between the left and right subtrees becomes 2.
  • 균형 값이 1보다 크면 왼쪽이 높고, -1보다 작으면 오른쪽이 높습니다.
    A balance factor greater than 1 means the left side is taller; less than -1 means the right side is taller.
풀이 코드 보기 / View Solution Code (p2.py) 
class Node:
    def __init__(self, key):
        self.key = key
        self.height = 1
        self.left = None
        self.right = None


def height(node):
    return node.height if node else 0


def update(node):
    node.height = 1 + max(height(node.left), height(node.right))


def rotate_right(y):
    x = y.left
    y.left = x.right
    x.right = y
    update(y)
    update(x)
    return x


def rotate_left(x):
    y = x.right
    x.right = y.left
    y.left = x
    update(x)
    update(y)
    return y


def bst_insert(root, key):
    if root is None:
        return Node(key)
    if key < root.key:
        root.left = bst_insert(root.left, key)
    elif key > root.key:
        root.right = bst_insert(root.right, key)
    update(root)
    return root


def avl_insert(root, key):
    if root is None:
        return Node(key)

    if key < root.key:
        root.left = avl_insert(root.left, key)
    elif key > root.key:
        root.right = avl_insert(root.right, key)
    else:
        return root

    update(root)
    balance = height(root.left) - height(root.right)

    # 왼쪽이 너무 높은 경우 / Left-heavy
    if balance > 1:
        if key > root.left.key:       # LR case
            root.left = rotate_left(root.left)
        return rotate_right(root)     # LL case

    # 오른쪽이 너무 높은 경우 / Right-heavy
    if balance < -1:
        if key < root.right.key:      # RL case
            root.right = rotate_right(root.right)
        return rotate_left(root)      # RR case

    return root


def search_steps(root, key):
    count = 0
    while root:
        count += 1
        if key == root.key:
            return count
        root = root.left if key < root.key else root.right
    return count


# 메인 프로그램 / Main program
bst = None
avl = None

for number in range(1, 16):
    bst = bst_insert(bst, number)
    avl = avl_insert(avl, number)

print(f"BST: 높이 {height(bst)}, 15번 찾기 {search_steps(bst, 15)}번 비교")
print(f"AVL: 높이 {height(avl)}, 15번 찾기 {search_steps(avl, 15)}번 비교")
BST: 높이 15, 15번 찾기 15번 비교
AVL: 높이 4, 15번 찾기 4번 비교

BST는 15번을 찾으려고 15번 비교해야 하지만 AVL은 4번이면 됩니다. 데이터가 100만 개라면 BST는 최악 100만 번, AVL은 약 20번입니다.

The BST needs 15 comparisons to find 15, while the AVL tree needs only 4. With one million values, the worst case for a BST can require one million comparisons, while an AVL tree needs about 20.

문제 3. 영화관 좌석 예약 (Red-Black Tree)

좌석 번호로 예약 요청이 들어옵니다. 이미 예약된 좌석이면 "이미 예약됨"을 출력하고, 마지막에 예약된 좌석을 번호 순서로 출력하세요. 각 노드의 색도 함께 출력합니다.

Seat reservation requests arrive as seat numbers. If a seat has already been reserved, print “Already reserved.” At the end, print all reserved seats in ascending order, including each node's color.

입력과 출력 예시 / Sample Input and Output

  • 입력 / Input: 10, 20, 30, 40, 50, 25, 30
  • 출력 / Output: 각 요청의 결과, 30번은 두 번째 요청에서 중복
    The result of each request; the second request for seat 30 is a duplicate.

힌트 / Hints

  • 새 노드는 항상 빨강으로 넣습니다.
    A newly inserted node is always red.
  • 오른쪽이 빨강이면 왼쪽 회전, 왼쪽에 빨강이 연속이면 오른쪽 회전, 양쪽이 모두 빨강이면 색 뒤집기 color flip를 합니다.
    If the right link is red, rotate left. If two consecutive left links are red, rotate right. If both children are red, flip colors.
  • 삽입이 끝나면 루트를 검정으로 칠합니다.
    After each insertion, color the root black.
풀이 코드 보기 / View Solution Code (p3.py) 
RED = "R"
BLACK = "B"


class Node:
    def __init__(self, seat, color=RED):
        self.seat = seat
        self.color = color
        self.left = None
        self.right = None


def is_red(node):
    return node is not None and node.color == RED


def rotate_left(h):
    # 오른쪽의 빨간 링크를 왼쪽으로 이동
    # Move a red link from the right to the left
    x = h.right
    h.right = x.left
    x.left = h
    x.color = h.color
    h.color = RED
    return x


def rotate_right(h):
    x = h.left
    h.left = x.right
    x.right = h
    x.color = h.color
    h.color = RED
    return x


def flip_colors(h):
    # 업로드된 C 코드와 같은 색 변경 규칙
    # Use the same color assignment as the original C code
    h.color = RED
    h.left.color = BLACK
    h.right.color = BLACK


def insert(h, seat):
    if h is None:
        return Node(seat), False

    duplicate = False
    if seat < h.seat:
        h.left, duplicate = insert(h.left, seat)
    elif seat > h.seat:
        h.right, duplicate = insert(h.right, seat)
    else:
        return h, True

    # LLRB insertion fix-up rules
    if is_red(h.right) and not is_red(h.left):
        h = rotate_left(h)
    if is_red(h.left) and is_red(h.left.left):
        h = rotate_right(h)
    if is_red(h.left) and is_red(h.right):
        flip_colors(h)

    return h, duplicate


def inorder(h):
    if h is None:
        return
    inorder(h.left)
    print(f"{h.seat}({h.color})", end=" ")
    inorder(h.right)


# 메인 프로그램 / Main program
requests = [10, 20, 30, 40, 50, 25, 30]
root = None

for seat in requests:
    root, duplicate = insert(root, seat)
    root.color = BLACK  # 루트는 항상 검정 / The root is always black
    if duplicate:
        print(f"{seat}번 좌석은 이미 예약됨")
    else:
        print(f"{seat}번 좌석 예약 완료")

print("예약 목록: ", end="")
inorder(root)
print()

20번 좌석 예약 완료
30번 좌석 예약 완료
40번 좌석 예약 완료
50번 좌석 예약 완료
25번 좌석 예약 완료
30번 좌석은 이미 예약됨
예약 목록: 10(B) 20(R) 25(R) 30(B) 40(B) 50(B)

이 코드는 Red-Black Tree를 간단하게 구현하는 Left-Leaning Red-Black Tree(LLRB)입니다. 빨간 노드를 항상 왼쪽에만 두도록 제한해서 삽입 수정 규칙을 세 가지로 정리합니다. 루트 검정, 빨강 연속 금지, 검정 높이 동일 규칙은 일반 Red-Black Tree와 같습니다.

This code uses a Left-Leaning Red-Black Tree (LLRB), a simplified form of a Red-Black Tree. By requiring red links to lean left, insertion fix-up can be expressed with three rules. Its core properties—black root, no consecutive red links, and equal black height—are the same as those of a conventional Red-Black Tree.
