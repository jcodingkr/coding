1. Splay Tree 핵심 개념 / Core Concept

Splay Tree는 자체 균형 이진 탐색 트리(Self-adjusting Binary Search Tree)입니다. 노드를 검색하거나 삽입·삭제할 때 접근한 노드를 회전시켜 루트로 이동시킵니다.

A Splay Tree is a self-adjusting binary search tree. When a node is searched, inserted, or deleted, rotations move the accessed node toward the root.

AVL Tree나 Red-Black Tree처럼 항상 정해진 균형 조건을 유지하는 것이 아니라, 최근에 접근한 노드를 루트 가까이에 두는 방식입니다.

Unlike AVL or Red-Black Trees, it does not maintain a strict balance condition. Instead, it keeps recently accessed nodes near the root.

용어 / Term의미 / Meaning
Zig한 번 회전하여 부모가 루트가 되는 경우 / A single rotation that moves the child to the root.
Zig-Zig목표와 부모가 같은 방향에 있는 두 단계 회전 / Two rotations when target and parent lie in the same direction.
Zig-Zag목표와 부모가 반대 방향에 있는 두 단계 회전 / Two rotations when target and parent lie in opposite directions.
Splay목표 노드 또는 목표에 가장 가까운 노드를 루트로 이동 / Move the target or the closest node to the root.

3-1. 오른쪽 회전 (Zig) / Right Rotation

    new_root = node["left"]
    node["left"] = new_root["right"]
    new_root["right"] = node
    return new_root

4. Splay 연산 / The Splay Operation

splay(root, target)는 이 코드에서 가장 중요한 함수입니다. 목표값을 찾거나, 값이 없으면 탐색 경로에서 가장 가까운 노드를 루트로 이동시킵니다.

The splay(root, target) function is the core of this implementation. It moves the target to the root, or, if the target is absent, moves the last/closest node reached during the search to the root.

def splay(root, target):
    if root is None or root["val"] == target:
        return root

    if target < root["val"]:
        if root["left"] is None:
            return root

        if target < root["left"]["val"]:
            root["left"]["left"] = splay(root["left"]["left"], target)
            root = rotate_right(root)

        elif target > root["left"]["val"]:
            root["left"]["right"] = splay(root["left"]["right"], target)
            if root["left"]["right"] is not None:
                root["left"] = rotate_left(root["left"])

        return root if root["left"] is None else rotate_right(root)

    else:
        if root["right"] is None:
            return root

        if target < root["right"]["val"]:
            root["right"]["left"] = splay(root["right"]["left"], target)
            if root["right"]["left"] is not None:
                root["right"] = rotate_right(root["right"])

        elif target > root["right"]["val"]:
            root["right"]["right"] = splay(root["right"]["right"], target)
            root = rotate_left(root)

        return root if root["right"] is None else rotate_left(root)

구현을 읽을 때 주의 / Important Implementation Note

이 코드는 재귀적으로 아래쪽 서브트리를 Splay한 뒤, 현재 단계에서 회전을 수행하는 방식입니다. 회전 함수는 입력 노드의 링크를 직접 변경하므로, 호출 결과를 root 또는 해당 자식 링크에 다시 대입하는 것이 중요합니다.

This implementation recursively splays a lower subtree and then performs rotations at the current level. Since rotations modify links, assigning the returned subtree root back to root or the appropriate child link is essential.

6. 삽입 함수 / Insert Function

def insert(root, val):
    if root is None:
        return create_node(val)

    root = splay(root, val)

    if root["val"] == val:
        return root

    new_node = create_node(val)

    if val < root["val"]:
        new_node["right"] = root
        new_node["left"] = root["left"]
        root["left"] = None
    else:
        new_node["left"] = root
        new_node["right"] = root["right"]
        root["right"] = None

    return new_node

7. 삭제 함수 / Delete Function

def delete(root, val):
    if root is None:
        return None

    root = splay(root, val)

    if root["val"] != val:
        return root

    if root["left"] is None:
        return root["right"]
    else:
        right_subtree = root["right"]
        new_root = splay(root["left"], val)
        new_root["right"] = right_subtree
        return new_root

삭제할 노드를 먼저 루트로 올린 뒤 제거합니다. 왼쪽 서브트리가 있으면 그 안의 최댓값을 새 루트로 올리고, 원래 오른쪽 서브트리를 새 루트의 오른쪽에 연결합니다.

First bring the node to delete to the root. If a left subtree exists, bring its maximum node to the root, then attach the original right subtree to that new root's right side.

전체 Python 코드 펼치기 / Expand Complete Python Code 
def create_node(val):
    return {"val": val, "left": None, "right": None}


def rotate_right(node):
    new_root = node["left"]
    node["left"] = new_root["right"]
    new_root["right"] = node
    return new_root


def rotate_left(node):
    new_root = node["right"]
    node["right"] = new_root["left"]
    new_root["left"] = node
    return new_root


def splay(root, target):
    if root is None or root["val"] == target:
        return root

    if target < root["val"]:
        if root["left"] is None:
            return root

        if target < root["left"]["val"]:
            root["left"]["left"] = splay(root["left"]["left"], target)
            root = rotate_right(root)

        elif target > root["left"]["val"]:
            root["left"]["right"] = splay(root["left"]["right"], target)
            if root["left"]["right"] is not None:
                root["left"] = rotate_left(root["left"])

        return root if root["left"] is None else rotate_right(root)

    else:
        if root["right"] is None:
            return root

        if target < root["right"]["val"]:
            root["right"]["left"] = splay(root["right"]["left"], target)
            if root["right"]["left"] is not None:
                root["right"] = rotate_right(root["right"])

        elif target > root["right"]["val"]:
            root["right"]["right"] = splay(root["right"]["right"], target)
            root = rotate_left(root)

        return root if root["right"] is None else rotate_left(root)


def search(root, target):
    return splay(root, target)


def insert(root, val):
    if root is None:
        return create_node(val)

    root = splay(root, val)

    if root["val"] == val:
        return root

    new_node = create_node(val)

    if val < root["val"]:
        new_node["right"] = root
        new_node["left"] = root["left"]
        root["left"] = None
    else:
        new_node["left"] = root
        new_node["right"] = root["right"]
        root["right"] = None

    return new_node


def delete(root, val):
    if root is None:
        return None

    root = splay(root, val)

    if root["val"] != val:
        return root

    if root["left"] is None:
        return root["right"]
    else:
        right_subtree = root["right"]
        new_root = splay(root["left"], val)
        new_root["right"] = right_subtree
        return new_root


def print_tree(node, depth=0, side="Root"):
    if node is not None:
        print("   " * depth + f"[{side}] {node['val']}")
        print_tree(node["left"], depth + 1, "Left")
        print_tree(node["right"], depth + 1, "Right")


tree = None
numbers = [30, 20, 40, 35]

for num in numbers:
    tree = insert(tree, num)

print("--- 1. After inserting 30, 20, 40, 35 (35 becomes Root) ---")
print_tree(tree)

print_tree(tree)

가장 중요한 한 문장 / The Most Important Takeaway

Splay Tree는 “최근에 접근한 노드를 루트로 올려 다음 접근을 빠르게 할 가능성을 높이는 트리”입니다.

A Splay Tree moves recently accessed nodes toward the root, increasing the chance that subsequent accesses will be faster.

참고: 이 예제의 출력은 질문에 제공된 코드의 구조와 실행 흐름을 기준으로 설명했습니다. Splay Tree의 개별 연산은 최악의 경우 O(n)일 수 있지만, 연속된 연산의 상각 시간 복잡도는 O(log n)입니다.
