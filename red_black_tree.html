1-1. BST 복습 / BST Review

이진 탐색 트리(BST)는 왼쪽 자식 < 부모 < 오른쪽 자식 규칙을 지키는 트리입니다. 탐색·삽입 시간은 트리의 높이 h에 비례합니다: O(h).

A Binary Search Tree (BST) follows the rule left child < parent < right child. Search and insertion time are proportional to the tree height h: O(h).

A Binary Search Tree keeps left < parent < right. Search and insert take O(h), where h is the height.

Problem: Inserting 1, 2, 3, 4, 5 in order creates a straight-line tree (height 5), making operations O(n)—similar to searching a list.

Problem: Inserting 1,2,3,4,5 in order gives a straight line of height 5, so operations become O(n).

2-1. 레드-블랙 트리의 5가지 규칙 / The 5 Properties

#한국어English
1모든 노드는 빨강 또는 검정이다.Every node is red or black.
2루트는 검정이다.The root is black.
3모든 리프(NIL)는 검정이다.Every leaf (NIL) is black.
4빨강 노드의 자식은 둘 다 검정이다. (빨강이 연속 불가)A red node's children are both black (no two reds in a row).
5어떤 노드에서 리프까지 가는 모든 경로의 검정 노드 수(black-height)가 같다.Every path from a node to its leaves has the same number of black nodes (black-height).

위 그림의 트리에서 13 → 8 → 1 → NIL, 13 → 17 → 25 → 22 → NIL 경로를 따라 검정 노드를 세어 보세요. 모두 같습니다!

In the tree above, count the black nodes on the paths 13 → 8 → 1 → NIL and 13 → 17 → 25 → 22 → NIL. The counts are equal!

In the example tree, count black nodes along 13→8→1→NIL and 13→17→25→22→NIL. They match!

왜 높이가 O(log n)? 규칙 5로 검정 노드는 모든 경로에 bh개, 규칙 4로 빨강은 검정 사이에 최대 1개씩만 끼므로 가장 긴 경로 ≤ 2 × 가장 짧은 경로. 따라서 h ≤ 2·log₂(n+1). Why O(log n)? Rule 5 gives every path bh black nodes; Rule 4 allows at most one red between blacks, so longest ≤ 2 × shortest, hence h ≤ 2·log₂(n+1).

2-2. 회전 / Rotation

회전은 BST 규칙(좌 < 부모 < 우)을 깨지 않고 트리 모양만 바꾸는 O(1) 연산입니다. α, β, γ는 서브트리(회색)입니다.

A rotation changes only the tree shape in O(1), without violating the BST order (left < parent < right). α, β, and γ represent subtrees (shown in grey).

A rotation changes the tree's shape in O(1) without breaking the BST order. α, β, γ are subtrees (grey).

알고리즘 / Algorithm: Left-Rotate(x)

① y를 x의 오른쪽 자식으로 잡는다 ② y의 왼쪽 서브트리(β)를 x의 오른쪽으로 옮긴다 ③ y의 부모를 x의 부모로 연결한다 ④ x를 y의 왼쪽 자식으로 만든다. ① Let y = x.right ② Move y's left subtree (β) to x.right ③ Link y to x's old parent ④ Make x the left child of y.
LEFT-ROTATE(T, x)
  y ← x.right                  // 1. set y
  x.right ← y.left             // 2. move β
  if y.left ≠ NIL: y.left.parent ← x
  y.parent ← x.parent          // 3. link parent
  if x.parent = NIL:           T.root ← y
  else if x = x.parent.left:   x.parent.left ← y
  else:                        x.parent.right ← y
  y.left ← x                   // 4. x becomes y's left child
  x.parent ← y
// RIGHT-ROTATE is the mirror image (left ↔ right). 오른쪽 회전은 좌우 반전.
def left_rotate(self, x):
    y = x.right
    x.right = y.left
    if y.left is not self.NIL:
        y.left.parent = x
    y.parent = x.parent
    if x.parent is self.NIL:
        self.root = y
    elif x is x.parent.left:
        x.parent.left = y
    else:
        x.parent.right = y
    y.left = x
    x.parent = y

def right_rotate(self, x):          # 좌우만 반대 / mirror image
    y = x.left
    x.left = y.right
    if y.right is not self.NIL:
        y.right.parent = x
    y.parent = x.parent
    if x.parent is self.NIL:
        self.root = y
    elif x is x.parent.right:
        x.parent.right = y
    else:
        x.parent.left = y
    y.right = x
    x.parent = y

의사코드 / Pseudo code

RB-INSERT(T, z)
  y ← NIL;  x ← T.root
  while x ≠ NIL:                       // BST descent
      y ← x
      x ← (z.key < x.key) ? x.left : x.right
  z.parent ← y
  if y = NIL: T.root ← z
  else if z.key < y.key: y.left ← z else y.right ← z
  z.left ← z.right ← NIL;  z.color ← RED
  RB-INSERT-FIXUP(T, z)

RB-INSERT-FIXUP(T, z)
  while z.parent.color = RED:
      if z.parent = z.parent.parent.left:
          u ← z.parent.parent.right                // uncle 삼촌
          if u.color = RED:                        // Case 1
              z.parent.color ← BLACK;  u.color ← BLACK
              z.parent.parent.color ← RED
              z ← z.parent.parent
          else:
              if z = z.parent.right:               // Case 2
                  z ← z.parent;  LEFT-ROTATE(T, z)
              z.parent.color ← BLACK               // Case 3
              z.parent.parent.color ← RED
              RIGHT-ROTATE(T, z.parent.parent)
      else: same with "left" ↔ "right"
  T.root.color ← BLACK                             // Rule 2
RED, BLACK = True, False

class Node:
    def __init__(self, key, color=RED, nil=None):
        self.key, self.color = key, color
        self.left = self.right = self.parent = nil

class RedBlackTree:
    def __init__(self):
        self.NIL = Node(None, BLACK)      # 모든 리프가 공유하는 검정 NIL
        self.root = self.NIL

    # left_rotate, right_rotate : 2교시 코드 그대로 사용

    def search(self, key):
        x = self.root
        while x is not self.NIL and key != x.key:
            x = x.left if key < x.key else x.right
        return x

    def insert(self, key):
        z = Node(key, RED, self.NIL)
        y, x = self.NIL, self.root
        while x is not self.NIL:
            y = x
            x = x.left if key < x.key else x.right
        z.parent = y
        if y is self.NIL:      self.root = z
        elif key < y.key:      y.left = z
        else:                  y.right = z
        self._fix_insert(z)

    def _fix_insert(self, z):
        while z.parent.color == RED:
            gp = z.parent.parent
            if z.parent is gp.left:
                u = gp.right
                if u.color == RED:                    # Case 1
                    z.parent.color = u.color = BLACK
                    gp.color = RED
                    z = gp
                else:
                    if z is z.parent.right:           # Case 2
                        z = z.parent
                        self.left_rotate(z)
                    z.parent.color = BLACK            # Case 3
                    z.parent.parent.color = RED
                    self.right_rotate(z.parent.parent)
            else:                                     # 좌우 반대 / mirror
                u = gp.left
                if u.color == RED:
                    z.parent.color = u.color = BLACK
                    gp.color = RED
                    z = gp
                else:
                    if z is z.parent.left:
                        z = z.parent
                        self.right_rotate(z)
                    z.parent.color = BLACK
                    z.parent.parent.color = RED
                    self.left_rotate(z.parent.parent)
        self.root.color = BLACK

    def show(self, n=None, depth=0):                  # 눈으로 확인하기
        n = self.root if n is None else n
        if n is self.NIL: return
        self.show(n.right, depth + 1)
        print("    " * depth + f"{n.key}({'R' if n.color else 'B'})")
        self.show(n.left, depth + 1)

t = RedBlackTree()
for k in [1, 2, 3, 4, 5, 6, 7]:
    t.insert(k)
t.show()          # 높이가 3으로 유지됨! / height stays 3

4-1. 삭제 개념 / Deletion concept

삭제는 삽입보다 어렵습니다. 검정 노드를 지우면 규칙 5가 깨지기 때문입니다. 전체 흐름만 이해합시다.

Deletion is harder than insertion because removing a black node can violate Rule 5. For this lesson, focus on understanding the overall process.

Deletion is harder than insertion because removing a black node breaks Rule 5. We study the overall flow.

RB-DELETE(T, z)
  1. BST처럼 삭제 (자식이 둘이면 후계자 successor로 대체)   // delete like a BST
  2. 실제로 제거된(또는 옮겨진) 노드의 원래 색을 기억        // remember original colour
  3. 그 색이 RED   → 끝 (규칙 위반 없음)                    // nothing breaks
  4. 그 색이 BLACK → 대체 노드 x가 "이중 검정(extra black)"  // fix-up needed
       형제 w의 색과 w의 자식 색에 따라 4가지 경우:
       Case 1: w가 RED           → 회전+재색칠 후 Case 2~4로
       Case 2: w, w의 자식 모두 BLACK → w를 RED로, extra black을 위로 보냄
       Case 3: w의 먼 쪽 자식이 BLACK, 가까운 쪽이 RED → w 회전 → Case 4
       Case 4: w의 먼 쪽 자식이 RED → 회전 1번으로 종료

def height(t, n=None):
    n = t.root if n is None else n
    if n is t.NIL: return 0
    return 1 + max(height(t, n.left), height(t, n.right))

def black_height(t, n):                 # 문제 3 / Ex.3
    if n is t.NIL: return 0
    l, r = black_height(t, n.left), black_height(t, n.right)
    if l == -1 or r == -1 or l != r: return -1      # 규칙 5 위반 / Rule 5 broken
    return l + (0 if n.color == RED else 1)

def is_valid(t):                        # 문제 4 / Ex.4
    if t.root.color == RED: return False            # 규칙 2
    def ok(n):
        if n is t.NIL: return True
        if n.color == RED and (n.left.color == RED or n.right.color == RED):
            return False                            # 규칙 4
        return ok(n.left) and ok(n.right)
    return ok(t.root) and black_height(t, t.root) != -1
