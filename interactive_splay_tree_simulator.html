알고리즘 흐름 / Algorithm Flow

SEARCH / INSERT / DELETE | v SPLAY(target) | +----+----+ | | target closest found node reached | | +----+----+ | ROTATE | update tree root

Splay는 목표 노드가 없을 때에도 탐색 경로의 마지막 노드를 루트로 올립니다.

Even if the target is absent, splaying moves the last node reached on the search path to the root.

Zig / Zag

부모가 루트일 때 한 번 회전합니다.A single rotation when the parent is the root.

Zig-Zig / Zag-Zag

목표와 부모가 같은 방향에 있어 같은 방향으로 두 번 회전합니다.Two rotations in the same direction when target and parent align.

Zig-Zag / Zag-Zig

목표와 부모가 반대 방향에 있어 서로 다른 방향으로 회전합니다.Two rotations in opposite directions when target and parent form a zig-zag.

Amortized Complexity

연속된 연산의 상각 시간 복잡도는 O(log n)입니다. 단일 연산은 최악 O(n)일 수 있습니다.Amortized O(log n) per operation over a sequence; a single operation can be O(n) worst-case.
